# Purpose

BioCubed is an interactive 3D biography and portfolio experience built with HTML, CSS, and JavaScript.

The project was originally created as part of a job application requirement for an AI-focused position. The goal was to create a "vibe-coded experience" that communicates information in a memorable and interactive way.

Although initially designed for a hiring process, BioCubed is intended to be reusable. The cards, content, colors, and categories can easily be replaced by other developers to create:

* Personal portfolios
* Interactive resumes
* Company presentations
* Product demonstrations
* Educational experiences
* Storytelling environments
* Exhibition or kiosk displays

---

# Features

## Interactive 3D Cube

* Four walls containing category cards.
* Smooth rotation using mouse or touch gestures.
* Responsive layout for desktop and mobile devices.

## Dual Interaction System

Cards support two behaviors:

* Drag a card → rotate the cube.
* Click or tap a card → open additional information.

This allows users to naturally interact with the experience without accidentally opening content while rotating.

---

## Modal Navigation

Each category contains multiple pages of information.

Users can:

* Move forward and backward between pages.
* Close the information window.
* Return to the welcome screen.

---

# Why Everything Is Contained In One File

BioCubed intentionally uses a single **index.html** file.

Many modern web applications separate code into:

* HTML files
* CSS stylesheets
* JavaScript files
* Modules
* Build systems

For this project, simplicity and portability were considered more important than architectural complexity.

---

## Easy Distribution

Users can download a single file and immediately open it in a browser.

No installation is required.

No build process is required.

---

## Avoiding Module and CORS Issues

Projects using JavaScript modules frequently encounter browser security restrictions when opened directly as local files.

Typical errors include:

* CORS violations
* Module loading failures
* MIME type issues
* Missing local server requirements

Because BioCubed is contained in one file:

* It can run directly from the filesystem.
* No localhost server is required.
* No Node.js installation is required.
* No npm packages are required.
* No additional configuration is necessary.

This makes the project highly portable and easy to archive, share, or demonstrate.

---

## Faster Review

Recruiters, hiring managers, and developers can inspect the entire project from a single file without navigating a larger codebase.
